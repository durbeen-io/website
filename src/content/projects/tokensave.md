TokenSave is a macOS automation that converts PDF, Word, Excel and PowerPoint files into Markdown, so AI tools can read them as clean text. It uses MarkItDown and Hazel. It flags files that need OCR and estimates how many tokens a file will use.

Version 1.0 is complete. The repository is private.
